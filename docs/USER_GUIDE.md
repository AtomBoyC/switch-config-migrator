## 准备工作

1. **Console 线**：RJ45 转 USB（或 RJ45 转 DB9 + USB 转串口）。
2. **串口驱动**：
   - Windows：在「设备管理器 → 端口 (COM 和 LPT)」中能看到 `COM3` 之类的端口即可，看不到请安装 CH340 / PL2303 / FTDI 驱动。
   - macOS：串口一般显示为 `/dev/cu.usbserial-xxxx` 或 `/dev/cu.wchusbserial-xxxx`。
3. **关闭占用串口的软件**：SecureCRT、Xshell、PuTTY 等，否则本工具无法打开串口。
4. **登录信息**：旧交换机 Console 口如设置了用户名/密码，填到顶部「用户名 / 密码」栏；思科/锐捷如需 enable 密码，填「enable密码」。
   不填也可以，工具遇到密码提示时会弹框询问。

## 界面总览

顶部为**串口连接参数**，下方为按步骤排列的 6 个标签页：

| 区域 | 说明 |
|---|---|
| 串口 | 选择 Console 线对应的串口，插拔后点「刷新」 |
| 波特率 | 绝大多数交换机为 **9600**；部分新款设备为 115200 |
| 编码 | 配置中有中文描述时，华三/华为通常为 **gbk**，乱码时可切换 utf-8 |
| 用户名/密码/enable密码 | 可选 |

> 所有备份和报告保存在 `用户目录/SwitchMigrator/`（Windows 为 `C:\Users\<用户名>\SwitchMigrator\`）。

## 第①步 读取旧交换机配置

1. Console 线接**旧交换机**。
2. 点击 **「连接并读取旧交换机配置」**。工具会自动：
   - 唤醒终端并登录（处理用户名/密码提示）
   - 识别厂商（`display version` / `show version`）
   - 关闭分页（`screen-length disable` / `terminal length 0`），即使关闭失败也会自动翻页
   - 读取全部配置（`display current-configuration` / `show running-config`）
   - **自动备份** 到 `SwitchMigrator/backup_<厂商>_<时间>.cfg`
3. 读取完成后，上方绿色文字显示解析统计，例如：
   `厂商: 华三 H3C   VLAN: 11 个   物理端口: 52 个（有配置 30 个）   聚合口: 2   VLAN 接口: 4 ...`

**其他方式**：如果已经用 CRT 导出过配置，点 **「从文件导入配置…」**；也可以把配置直接粘贴进文本框，再点「重新解析」。
自动识别厂商不准时，可在「源厂商」下拉框手动指定。

> 对旧交换机只执行查看类命令，**不会修改旧交换机的任何配置**。

## 第②步 读取新交换机端口

1. 「新交换机厂商」选择 **锐捷 Ruijie**（连接后会自动识别并修正）。
2. Console 线换到**新交换机**，点击 **「连接新交换机并读取端口列表」**。
3. 工具执行 `show interface status`（华三/华为为 `display interface brief`），提取所有物理端口，例如：
   `新交换机(ruijie) 物理端口 28 个: GE × 24，10GE × 4`

新设备首次开机常见的交互会自动处理：

| 设备提示 | 自动处理 |
|---|---|
| 华三 `Automatic configuration is running, press CTRL_C or CTRL_D to break` | 发送 Ctrl+D 中止自动配置 |
| 华为 `Auto-Config is working ... stop Auto-Config? [Y/N]` | 回答 y |
| 锐捷/思科 `initial configuration dialog? [yes/no]` | 回答 no |
| 首次登录要求设置新密码 | 弹框让你输入 |

## 第③步 端口映射

工具会把旧端口自动对应到新端口，规则是 **同速率、同位置**：

- 旧的第 N 个千兆口 → 新的第 N 个千兆口（`GigabitEthernet1/0/5` → `GigabitEthernet 0/5`）
- 旧的第 1 个万兆口 → 新的第 1 个万兆口（`Ten-GigabitEthernet1/0/49` → `TenGigabitEthernet 0/25`）
- IRF / 堆叠多成员设备：成员 1 对应新设备的第一组端口，成员 2 对应第二组，依此类推

这样新设备上架时，**跳线可以按原来的位置插**。

| 操作 | 说明 |
|---|---|
| 双击「新端口」列 | 从下拉框选择其他端口，或选 `(不迁移)` |
| 只显示有配置的端口 | 隐藏默认配置的空闲端口，便于检查 |
| 导出 / 导入映射表 CSV | 可用 Excel 编辑后导回；同型号批量替换时可复用 |
| 红色行 | 该端口有配置，但没有对应的新端口（例如新设备万兆口数量更少），**必须处理** |

> 聚合组按原编号迁移：`Bridge-Aggregation1` → `AggregatePort 1`。

## 第④步 预览与编辑配置

点「下一步：生成配置 →」后：

- **左侧**：将要下发的新设备命令，**可以直接编辑**（增删改都行），下发以左侧内容为准。
- **右上「提示 / 需人工处理」**：例如
  - `用户/认证/登录配置未迁移：密码为密文无法跨厂商转换，请在新设备上手动配置管理账号`
  - `GigabitEthernet1/0/3: hybrid 端口已转换为 trunk (native 10)`
  - `GigabitEthernet 0/1 有 1 条命令未转换: broadcast-suppression 5`
- **右下「未自动转换的原始配置」**：如 ACL、QoS 等，对照手动配置。

可「导出配置到文件」留档，或者交给同事审核。

## 第⑤步 一键下发

| 选项 | 说明 |
|---|---|
| 遇到错误立即停止 | 默认关闭（失败的命令记下来，继续下发后续命令） |
| 下发完成后保存配置 | 默认开启；如有失败命令会先询问是否仍然保存 |
| 单条命令超时 | 默认 20 秒 |

点击 **「▶ 开始一键下发」**：

1. 弹窗确认 Console 线已接到**新交换机**。
2. 工具登录后再次识别设备品牌；**如果与目标配置不一致（可能接错设备），会要求输入 yes 才继续**。
3. 进入配置模式（`system-view` / `configure terminal`），逐行发送，等待提示符返回，并检查设备返回中是否有错误信息：
   - 华三：`% Unrecognized command`、`% Wrong parameter` …
   - 华为：`Error: …`
   - 锐捷/思科：`% Invalid input detected`、`% Incomplete command` …
4. 绿色 `[OK ]` 为成功，红色 `[ERR]` 为失败（附设备返回的错误信息）。
5. 结束后保存配置（`save force` / `save` / `write` / `write memory`），并生成报告 `SwitchMigrator/push_report_<时间>.txt`。

失败的命令一般是该型号不支持或语法略有差异，在「串口终端」页手动补配即可。

## 串口终端

一个简易终端，显示串口的全部收发内容：

- 自动流程卡住时，可以在这里看到设备实际输出了什么
- 底部输入框可以手动发送命令；提供 Ctrl+C、Ctrl+D、空格翻页按钮
- 可用于下发后的检查，如 `show running-config`、`show vrrp brief`

## 离线模式

没有新设备、只想先生成配置让同事审核：

1. 第①步导入旧配置文件；
2. 第②步选择新交换机厂商，设置「端口编号模板」（如锐捷单机 `0/{n}`，`{n}` 为旧端口末位编号），
   或把新设备的 `show interface status` 输出粘贴到文本框，点「用下面粘贴的端口列表」；
3. 第③④步生成并导出配置。

也可以使用命令行：

```bash
python main.py --cli old.cfg --to ruijie --ports new_ports.txt -o new.txt
```

## 割接检查清单

下发完成后、上架替换前建议逐项核对：

- [ ] 第④步「需人工处理」的项目已全部处理（尤其是**管理账号、SSH/Telnet 登录方式**）
- [ ] VLAN 数量与旧设备一致：`show vlan` / `display vlan brief`
- [ ] 上联聚合口成员、模式（LACP/静态）与核心侧一致
- [ ] 网关 IP、VRRP 虚拟 IP 与优先级正确，主备关系符合预期
- [ ] DHCP 中继服务器地址正确
- [ ] 静态路由 / OSPF 配置正确
- [ ] 下发报告中无失败命令，或失败命令已手动补配
- [ ] 配置已保存，必要时重启验证
- [ ] 旧配置备份文件已留存

## 常见问题

**Q：点了“连接”没反应 / 提示等待提示符超时？**
A：检查波特率（9600/115200），切到「串口终端」页看设备是否有输出；部分设备需要先按几次回车，可在终端页手动登录后再重试。

**Q：提示“无法打开串口”？**
A：串口被 SecureCRT 等软件占用，或 USB 线已拔出，关闭占用软件或点「刷新」后重选。

**Q：读取出来的中文描述是乱码？**
A：切换「编码」（gbk / utf-8）后重新读取。

**Q：新设备端口比旧设备少怎么办？**
A：映射表中会出现红色行，手动把重要端口映射到空闲端口，不需要的选 `(不迁移)`。

**Q：hybrid 端口怎么处理？**
A：锐捷/思科没有华三那样通用的 hybrid，工具会自动转换：只有一个 untagged VLAN → access；一个 untagged + 若干 tagged → trunk（native 为 untagged VLAN）。多个 untagged VLAN 的情况无法等价转换，会醒目提示人工处理。

**Q：能用于同品牌替换吗？**
A：可以，例如 H3C → H3C 不同型号，工具同样会做端口映射和命令重新生成。
